# CineMind: movie success prediction, box-office forecasting and recommendation

```
python train.py          # cleans data, trains + tunes models, writes models/ figures/ metrics.json
streamlit run app.py     # 4-tab web app
python build_report.py   # rebuilds the Word report from metrics.json
```
Data: IMDb 5000 movie dataset in data/movie_metadata.csv (public, Kaggle).
